# 排球隊得分紀錄板

用來記錄排球隊員得分、攻擊、失誤數據的網頁工具。

## 功能
- 自訂新增 / 刪除球員（刪除前會需要確認，避免手滑誤刪）
- 得分類：得分、攻擊得分、發球得分、攔網得分
- 失誤類：失誤、攻擊失誤、發球失誤、接球失誤、舉球失誤、觸網失誤
- 得分與失誤分成兩欄顯示
- 自動計算每位球員與全隊總分（得分加總 − 失誤加總）
- 資料自動儲存在瀏覽器（重新整理、關閉分頁不會消失）
- 一鍵匯出 CSV 成績表
- **（選用）建立房間分享**：跟隊友輸入同一組房間代碼，就能即時共用同一份紀錄

## 本機開發
\`\`\`bash
npm install
npm run dev
\`\`\`

## 部署
推送到 GitHub 的 main 分支後，GitHub Actions 會自動建置並部署到 GitHub Pages。
記得到 repo 的 Settings > Pages，將 Source 設定為 "GitHub Actions"。

## 設定「分享房間」功能（選用）

這個功能預設是關閉的，不設定完全不影響本機記錄，網頁會自動隱藏相關按鈕的作用（點了會提示尚未設定）。

1. 前往 https://console.firebase.google.com 用 Google 帳號登入
2. 點「新增專案」，輸入名稱（例如 `volleyball-score`），一路下一步建立（可以關掉 Google Analytics，不影響功能）
3. 左側選單找「Build」→「Firestore Database」，點「建立資料庫」
   - 位置選離你近的（例如 `asia-east1`）
   - 安全性規則先選「測試模式」（30 天內任何人可讀寫，之後可再自行收緊規則）
4. 回到專案總覽頁，點網頁圖示（`</>`）新增一個網頁應用程式，取個名字，完成後會顯示一段 `firebaseConfig` 設定
5. 打開專案裡的 `src/firebaseConfig.js`，把裡面的空字串換成你剛剛複製的值
6. 存檔、`git add -A`、`git commit`、`git push`，等自動部署完成即可

設定完成後，網頁上方會出現「建立房間分享」跟「加入房間」的按鈕：
- **建立房間分享**：產生一組 6 碼代碼，把代碼傳給隊友
- **加入房間**：隊友輸入同一組代碼，就會看到跟你一樣的即時資料，雙方的按鈕動作會同步更新

### 使用限制
- 這是「最後寫入為主」的簡易同步，如果兩人在同一瞬間對同一位球員按下按鈕，其中一次操作有極小機率會被覆蓋，建議多人同時使用時盡量錯開操作
- 免費額度足夠一般球隊日常使用，不會有費用問題
- 如果之後想關閉分享功能，把 `src/firebaseConfig.js` 裡的值清空即可
