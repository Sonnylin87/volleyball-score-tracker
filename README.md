# 排球隊得分紀錄板

用來記錄排球隊員得分、攻擊、失誤數據的網頁工具。

## 功能
- 自訂新增 / 刪除球員（刪除前會需要確認，避免手滑誤刪）
- 得分類：得分、攻擊得分、發球得分、攔網得分
- 失誤類：失誤、攻擊失誤、發球失誤、接球失誤、舉球失誤、觸網失誤
- 得分與失誤分成兩欄顯示
- 自動計算每位球員與全隊總分（得分加總 − 失誤加總）
- 資料自動儲存在瀏覽器（重新整理、關閉分頁不會消失）
- 一鍵匯出 CSV 成績表
- **進階功能：輪轉站位分析**（需先新增球員才能使用）
  - 排球場站位圖，上排＝前排（靠近球網）、下排＝後排（發球區），1 號位在左上，順時鐘排列
  - 可指定每個站位由哪位球員站，並用「順轉／逆轉」按鈕模擬輪轉換位（換位時會有轉場動畫）
  - 點選場上球員即可跳出他的記分板直接記錄
  - **自由球員**：可指定一位球員為自由球員，按「自由球員上場」會跟目前站在 4 號位的球員互換上場；輪轉到 1 號位時會自動換回原本的球員（也能手動按「自由球員下場」提前換回）
  - 自動分析：**輪轉站位（整組陣型）數據**——依「場上6人當時的整組排列組合」分組，找出得分率最高／最弱的整組輪轉陣型，這才是真正的「這一輪站位」；另外也有依「站位編號 1~6」加總的參考數據
  - 各站位／各輪轉陣型的最長連續失分、最長連續得分／失分（順風逆風波段）、局末關鍵分（總分達 20 分後）表現
  - 可另外匯出這份進階分析的 CSV（含輪轉區位數據與連續失分最多站位）
  - 「重設本局數據」會同時清除輪轉紀錄與所有球員的得分／失誤數據

## 本機開發
\`\`\`bash
npm install
npm run dev
\`\`\`

## 部署
推送到 GitHub 的 main 分支後，GitHub Actions 會自動建置並部署到 GitHub Pages。
記得到 repo 的 Settings > Pages，將 Source 設定為 "GitHub Actions"。
